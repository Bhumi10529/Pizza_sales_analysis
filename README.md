# 🍕 Pizza Sales Analysis Dashboard

## 📌 Project Overview
An interactive Pizza Sales Analysis Dashboard built using Microsoft Power BI to analyze sales performance, revenue trends, customer orders, and pizza preferences.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel / CSV

## 📊 Key Performance Indicators
- **Total Revenue:** $817.86K
- **Total Orders:** 21K
- **Total Pizzas Sold:** 50K
- **Average Order Value:** $38.31

## 📈 Dashboard Features
- Revenue Trend Over Time
- Pizza Sales Volume Trend
- Top 5 Best-Selling Pizzas
- Revenue by Pizza Category
- Revenue by Pizza Size
- Quantity by Pizza Size
- Interactive Category and Date Filters

## 💡 Key Business Insights
- Classic category generated the highest revenue.
- Large pizzas contributed the highest revenue among pizza sizes.
- The dashboard provides an overview of sales and order performance.
- Top-selling pizzas can be identified through revenue analysis.

## 📁 Project Files
- `pizza.sales.dashboard.pbix` – Power BI dashboard
- `pizza_sales.csv` – Dataset
- Dashboard screenshot – Visual preview

## 🚀 Project Objective
To transform raw pizza sales data into meaningful business insights through interactive data visualization and analysis.
